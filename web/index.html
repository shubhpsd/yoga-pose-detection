🚀 Project Highlights

🧠 Advanced Neural Network

Custom attention-based architecture that learns to focus on important body landmarks for each yoga pose.

📊 107 Pose Classes

Trained to recognize 107 different yoga poses from Downward Dog to complex arm balances.

⚖️ SMOTE Balancing

Uses advanced oversampling techniques to handle class imbalance and improve accuracy.

🎯 MediaPipe Integration

Leverages Google's MediaPipe for accurate pose landmark detection in real-time.

📈 75%+ Accuracy

Achieves competitive accuracy on this challenging multi-class classification problem.

⚡ Optimized Training

AdamW optimizer, cosine annealing, label smoothing, and early stopping for robust training.
